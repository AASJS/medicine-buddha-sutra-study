## 三、十二大願摘要

經文核心為藥師如來行菩薩道時所發十二大願，總體精神是「以自身成佛功德力，回向一切眾生，令世間與出世間皆得圓滿」：

1. **光明莊嚴願** — 成佛身放無量光明，具三十二相、八十種好，令一切眾生與佛無異。
2. **身如琉璃願** — 佛身如琉璃內外清淨，光明勝日月，引導黑暗迷惘眾生。
3. **資生無盡願** — 以無邊智慧方便，令眾生受用無盡、無所乏少。
4. **安立大乘願** — 一切外道、聲聞、緣覺皆安立於菩提道（大乘）。
5. **戒行無缺願** — 於法中修梵行者皆得不缺減戒，不墮惡道。
6. **諸根具足願** — 殘障、醜陋、聾盲、癱瘓、麻風、癲狂等聞名皆得諸根圓滿（療身病）。
7. **除病離貧願** — 孤苦貧病、無醫無親者聞名眾患悉除，至成佛道。
8. **轉女成男願** — 厭患女身者聞名轉成丈夫相，直至成佛。
9. **正見解脫願** — 令眾生出離魔網邪見，安立正見，次第示菩薩行門（療心病）。
10. **解脫憂苦願** — 被囚禁、鞭撻、處死及遭無量災難者，憑佛福力解脫苦惱。
11. **先食後法願** — 為求食造惡的飢民，先以美食飽足其身，再以法味令究竟安樂。
12. **衣服莊嚴願** — 貧無衣被、寒熱蚊虻逼惱者，施與稱心衣服及香花鼓樂，令所需皆滿。

## 四、學習建議（由淺入深）

1. **先讀熟十二大願** — 全經骨架，每日誦一願、思其義。
2. **對照白話** — 以學習手冊「原文＋要義」逐段消化正宗分。
3. **抓三根主線** — ①佛願（十二大願）②佛土（淨琉璃）③佛名（聞名滅罪、免橫死）。
4. **落實實修** — 選「持名」或「誦經＋供燈／幡」任一簡便法。
5. **對照異譯** — 有條件可讀玄奘譯 T14n0450，看十二大願措辭與增益部分。
