② 逐文件摘要

1 · 经文原文 底本 KR6i0047_001.txt

《佛说药师如来本愿经》一卷，隋·天竺三藏达磨笈多译，CBETA 编号 T14n0449、高丽藏 KR6i0047。是《药师琉璃光如来本愿功德经》五种汉译中年代最早的一种，文字最为古朴。

全经结构：序分（佛在广严城乐音树下，曼殊室利启请）→ 正宗分（药师如来十二大愿、净琉璃世界、日光/月光二菩萨、闻名灭罪、受持功德与往生、供养仪轨、救脱菩萨说九横死与七难）→ 流通分（十二药叉大将誓护持经，大梵天王等闻法欢喜）。

注：本文件已在上一轮被通读并生成《药师经学习手册》，本报告聚焦「全库其余 5 个工程文件」。

2 · 项目说明 脚手架 README_20261109_051333.md

标题「药师琉璃光如来 · 圣为卡片」，定位为《药师经》图文卡项目的入口说明。要点：

  • 数据驱动出卡：文案写在 药师经/卡片数据.json，改 JSON 即改文案，脚本自动缩排并校验「白话/深一层/收尾」三段齐全、不溢出，统一 2160×3840。
  • 统一版式：金框、编号胶囊、金句区 + 三段式解读（白话 / 深一层 / 收尾）、关键词页脚。
  • 净琉璃配图：中国风工笔，敦煌壁画与水墨结合，净琉璃青金设色，符号化横幅插画，无水印。
  • 逐字出处：金句取自 CBETA T14n0449 隋·达摩笈多译，不编造、标出处。
  • 移植来源：明确说明本脚手架移植自《地藏经》图文卡项目 AASJS/dizangjing-cards（「艳暖的地藏经卡片 · 渡凡」），仅替换经文数据源与视觉主题（敦煌暖金 → 净琉璃青金）。

4 · 出卡脚本 工具链 药师经出卡脚本_make_card.py

渲染引擎，移植自地藏经项目，仅替换数据源与系列名。流程：

  1. 从 药师经/卡片数据.json 读取卡片文案；
  2. 用内置模板生成 9:16 HTML（逻辑尺寸 1080×1920）；
  3. 起本地 http server + playwright-cli，以 SCALE=2 直接出 2160×3840 PNG；
  4. 输出 cards/<序号>-<品名>.png。

关键设计：

  • card_ready() 硬规则：白话 / 深一层 / 收尾 三段齐全才出卡——这正是 12 张目前无法出卡的原因。
  • 防溢出：文案过长时逐级缩小正文字号（≤5 次），仍超界则抛 OVERFLOW 错误，保证卡片高度统一且不裁字。
  • 配图缺失兜底：图缺失时自动渲染「配图待放」占位框。
  • 双后端：优先 playwright-cli，缺失时回退本机 python playwright + chromium。

版式：金框（2px #bcae7a 直角）→ 系列名 + 编号胶囊 → 标题(76px) + 副题 → 配图区(940×740) → 金句引号框(含出处) → 三段式解读 → 页脚（品名全 + 关键词）。字体 Noto Serif SC / Songti SC。

5 · 配图提示词 视觉 配图提示词_20261109_051335.md

为卡片生成配图的提示词备档，统一风格：

中国风工笔插画，敦煌壁画石青石绿矿物重彩 + 掐丝珐琅琉璃透光质感，净琉璃青金设色，绢本质感，清润通透，琉璃光晕点缀

覆盖 15 张：12 张竖版愿卡（出图 1024×1536）+ 3 张横幅（净琉璃庄严 / 持名功德 / 十二药叉，出图 1536×1024）。

构图铁律（任何一张都不可破）：

  • 人物（含脸部五官）完整不被裁切；竖版主体居中、上下云海留白安全区；横幅人物头部绝不贴边、顶底留云纹空隙。
  • 不要任何文字与水印（出图后如有 AI 水印须裁掉）。
  • 命名严格对应 卡片数据.json 的「配图」字段（如 images/01-第一大愿.png）。
  • 关键特征锁定：本尊药师琉璃光如来（药钵/宝塔、施无畏印）、日光月光二菩萨胁侍、十二药叉拱卫；设色青绿主色 + 琉璃金线描；背景净琉璃国土、琉璃地、宝树罗网、祥云。

相对地藏经原版的变化：舍去「水墨结合」，改用「青绿矿物重彩 + 掐丝珐琅琉璃透光质感」，最贴净琉璃「清润通透」；视觉主题由敦煌暖金改为净琉璃青金。

  • 不承诺疗效：标注「经典愿力，非医疗承诺」；

⑤ 核心要点

  • 一句话定位：这是一套「把《药师经》拆成可随身读图文卡」的数据驱动脚手架，圣为风格、净琉璃青金视觉。
  • 设计哲学：单一数据源（JSON）→ 改文案不动代码；金句 + 三段式（白话/深一层/收尾）+ 关键词页脚的固定版式；终审权归人（draft 不出正式卡）。
  • 质量护栏：不虚构、不承诺疗效、出处必标、视觉不混用——四条红线把「佛经卡」与「普通知识卡」区分开。
  • 可复用性：移植自地藏经项目，意味着任何经典都能低成本复制同一条流水线。
  • 当前最大杠杆：把 12 张愿卡的「白话/深一层/收尾」填好，整条流水线即可转起来（出图、出卡、校对）。
